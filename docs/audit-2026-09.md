# PartyGames couch-party audit — September 2026

**Lens:** friends on a couch, one TV (host), phones as controllers. Screens should carry private prompts, votes, drawing, and tap-to-score. Talking, acting, and guessing happen in the room.

**Methodology:** engines, views, and content were reviewed in code; contract/smoke simulators ran every registered game at min and max players; `pnpm verify` was recorded; Playwright viewport matrix was executed. This is **not** a live 4- and 8-person living-room session. Findings that need a real couch are marked `needs-live`.

**Owners:** `engine` · `client` · `content` · `platform` · `test`

**Status:** `open` · `confirmed` · `fixed-this-pass`

## Grid Blast (Bomberman) — deep dive

**Files:** `grid-blast-engine.ts`, `grid-blast-logic.ts`, `GridBlastArena.tsx`, D-pad in `PlayerGameContent.tsx`.

| Topic | Finding | Sev |
|-------|---------|-----|
| Bomb capacity / range / kick on TV | Arena draws grid, bombs, fire, living players. **No** power-up sprites, range rings, or kick affordance. Player view exposes `blastRange` only | P1 |
| Kick | `canKick` set from crate; `cellFreeForPlayer` **blocks walking onto bombs**. Kick never runs | **P0** (dead feature) |
| Chains | Fire tiles orange on TV — readable if 3m away; 11×9 at 28px/cell is small on 720p | P1 |
| Round length | 3 rounds, last standing; **playing phase has no timer** (`clearPhaseTimer`). Can stall or end in seconds | P1 |
| Phone | D-pad + bomb `min-h-11`; landscape padding via player shell. One-thumb reach OK in portrait | P2 |
| Fairness | Soft-crate RNG power-ups (`bomb`, `range`, `speed`, `kick`) | P2 |
| Bots | None — 2 humans required; thin for a 1-host demo | P2 |
| Optional features | Team mode, shrinking arena, item roulette — **not present**; propose only if kick+HUD land | P3 |
| Couch fit | Real-time bomberman is **screen-heavy**; OK as arcade palate cleanser, not core social night | P2 |

**Proposal:** either implement kick + TV HUD (capacity, range, items) and a 90–120s round cap, or drop kick from the data model and market the game as a simpler blast-arena. Do not advertise kick until it works.
